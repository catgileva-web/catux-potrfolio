# Портфолио — Анна Иванова, UX Designer

Сайт-портфолио. Статика: HTML/CSS/JS, без сборщиков и зависимостей —
открывается прямо в браузере, хостится где угодно (GitHub Pages, Netlify).

## Структура

```
index.html          — разметка страницы
css/style.css        — все стили
js/script.js          — скролл-индикатор в нижней панели (title block)
assets/images/       — картинки проектов
content/             — черновики текстов (ббио, описания проектов)
CONTEXT.md           — бриф проекта: стиль, тон, договорённости
```

## Как посмотреть локально

Просто открыть `index.html` в браузере — бэкенда и сборки нет.

## Деплой

GitHub Pages: Settings → Pages → Source: `main` branch, папка `/root`.
Сайт появится на `https://<username>.github.io/<repo-name>/`.
