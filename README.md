# Портфолио — Катерина Гилёва, UX Designer

Сайт-портфолио «catux». Статика: HTML/CSS/JS, без сборщиков и зависимостей —
открывается прямо в браузере, хостится где угодно (GitHub Pages, Netlify).

## Структура

```
index.html          — разметка страницы
css/style.css        — все стили
js/script.js          — данные и логика (лента опыта, список кейсов, стики-футер навигации)
assets/images/       — картинки проектов
content/             — черновики текстов (bio, описания проектов)
CONTEXT.md           — бриф проекта: стиль, тон, договорённости
```

## Как посмотреть локально

Просто открыть `index.html` в браузере — бэкенда и сборки нет.

## Деплой

Автодеплой на GitHub Pages через Actions: `.github/workflows/pages.yml`
собирает и публикует сайт при каждом пуше в `main`.

Разово нужно включить источник в самом репозитории: Settings → Pages →
Source: **GitHub Actions** (вместо ветки). После этого сайт появится на
`https://<username>.github.io/<repo-name>/` и будет обновляться
автоматически с каждым мёржем в `main`.
